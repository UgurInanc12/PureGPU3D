PureGPU3D - Session Notes (2026-02-09)

1) Proje nedir / ne ise yarar
- PureGPU3D, yerel 2D videoyu SBS Full 3D videoya ceviren bir motordur.
- Hedef kullanim: VR gozlukte sol/sag goze farkli kareler vererek derinlik etkisi olusturmak.
- Ana pipeline:
  - Decode (NV12)
  - Depth + stereo isleme (2W x H SBS uretimi)
  - Encode
  - Audio remux (copy veya AAC)
- UI ve CLI uzerinden calisir.

2) Bugunun ana talepleri
- Cancel butonu bazen isi durdurmuyordu -> guvenilir, anlik cancel istendi.
- Pipeline performansi icin 8ms bandindan daha iyi optimizasyon plani istendi.
- GPU kullanim/fan/watt konusuna bottleneck analizi istendi (kernel disi sureleri ayristirma).
- Ses aktarimi / encoder / bitrate / container secimi / renk metadata korunumu beklentileri vardi.
- Son asamada: proje GitHub'a yayin hazir, English-only, minimal dosya seti, cift tikla calisma istendi.

3) Teknik olarak bugun ne yaptik (engine + UI)

3.1) Cancel guvenilirligi (ana fix)
- UI tarafi:
  - `Run Transcode` butonuna `trigger_mode="multiple"` eklendi.
  - `run_state` (is_running, run_id, cancel_event) eklendi.
  - Ayni butona ikinci tik geldiginde:
    - `cancel_event.set()`
    - `engine.abort_active_run()`
    - UI aninda "Cancel requested..." donuyor.
- Engine tarafi:
  - `StereoEngine.abort_active_run()` eklendi.
  - Aktif run context (backend + abort event) tutuluyor.
  - Encode future bekleme tam bloklu degil; kisa polling + cancel check ile calisiyor.
- Backend arayuzu:
  - `CodecBackend.request_abort()` eklendi.

3.2) FFmpeg backend abort (gercek process kill)
- FFmpeg backend aktif decode process ve writer process referanslarini tutuyor.
- `request_abort()` cagrisi:
  - decode process terminate/kill
  - writer abort/close
- Boylesiyle cancel sadece flag set degil, aktif subprocess'lere de uygulanmis oldu.

3.3) Pipeline optimizasyonu
- Decode prefetch:
  - Decode ayri thread + bounded queue ile calisiyor.
  - Decode ve isleme overlap oluyor.
- Kernel optimizasyonu:
  - Disparity hesap tek kernel'e alindi (`nv12_disparity_kernel`).
  - Y ve UV kernel'leri disparity map'i tuketiyor (tekrar hesap azaltildi).
  - GPU persistent buffer reuse eklendi (resolution bazli).
  - Mümkunse pinned host output bellek yolu eklendi.
  - Block/grid tuning: `block=(32, 8, 1)`.
- Decode cmd tuning:
  - CUDA path: `-extra_hw_frames 16`
  - Software path: `-threads 0`

3.4) Metrik ve bottleneck gorunurlugu
- Frame metric alanlari genisletildi:
  - `decode_wait_ms`
  - `encode_wait_ms`
  - `h2d_ms`
  - `kernel_compute_ms`
  - `d2h_ms`
- CSV/JSON metric ciktilari bu alanlari yazacak sekilde guncellendi.
- Stage timing warning metninde bu dagilim raporlanir hale geldi.

3.5) Robustluk (encoder/resolution uyumu)
- Genis SBS output (or. 7680 width) + `h264_nvenc` kombinasyonunda uyumsuzluk riskine karsi precheck eklendi.
- Auto secimde uygun fallback (`libx264`) deneniyor.
- Acik encoder seciliyse uyumsuzluk durumunda net hata veriliyor.
